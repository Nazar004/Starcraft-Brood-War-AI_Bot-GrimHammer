# Очистка площадки расширения — 2026-10-12

Пользователь сообщил о нестроящемся Command Center и попросил упростить цепочку «скан → уничтожение препятствия → строительство». Скриншот: Circuit Breaker, TvT_Anti2Factory, 34465-й кадр, 11047 минералов/1887 газа, резерв 400M. По самому скриншоту нельзя достоверно определить конкретный скрытый объект или причину отказа BWAPI.

В коде найдены обрывы цепочки:
- MapTools исключал базу при известном закопанном юните в footprint до создания задачи очистки.
- BuildingManager требовал предварительного исследования площадки и нахождения строителя не дальше шести тайлов для запуска очистки.
- Очистка переключала место расширения после 45 секунд либо после 12 секунд без готового Comsat и двух Vessel; общий тайм-аут задач также мог удалить её.
- Детекция разрешалась только при двух Vessel; одиночный Vessel попадал в ветку возврата домой.
- Очистка не принимала в качестве цели здания или нейтральные объекты.
- Собственный SCV, отведённый с площадки, не считался занятым для WorkerManager, запускающегося после BuildingManager.

Исправлено:
- Для Terran убрано исключение удаляемых объектов, пересекающих точный footprint CC, из-за одного только наличия объекта в памяти. Для видимых объектов допускаются разрушаемые вражеские здания, разрушаемые нейтралы и добываемые минералы. Прочие расы сохраняют старые правила.
- Для уже выбранной задачи очистка вызывается до проверки исследования, без радиуса шесть тайлов, без запрета по groundHitsFixed и без проверки partition id самой занятой клетки. Валидность участка/известная нейтральная база/строительный рельеф и отсутствие creep проверяются; штатный выбор расширения и строителя сохраняет проверки пути/опасности.
- Comsat скан вызывается напрямую через Micro::Scan при подозрении на скрытое препятствие, без очереди боевых сканов и запаса 100 энергии. Достаточно доступных 50 энергии. Активный скан не дублируется; неудачная попытка повторяется раз в 24 кадра.
- Без активного скана запрашивается Vessel; подходит один, включая одиночный Vessel без сопровождаемого отряда. Обычный уход от непосредственной воздушной опасности сохранён.
- Убраны оба тайм-аута переключения места. Пока задача помечена как очистка, общий тайм-аут строительства её не удаляет.
- Обнаруженную мину атакует строитель; мину не разминируют наездом Vulture. Другие доступные цели атакует SCV с прежней поддержкой Vulture. Минерал добывается с возвратом груза.
- Собственные блокирующие юниты отводятся прежним механизмом; WorkerManager не отменяет отвод SCV в этом кадре.
- После освобождения площадки сбрасывается прежний приказ Build и обновляются таймеры/счётчик отправок. Далее выполняется обычная выдача строительства на той же площадке.

Ограничения: скан не делает нестроительный рельеф или чужую занятую базу доступными; собственные постоянные здания и неразрушаемый декор не атакуются. Военную безопасность выбора новых расширений целиком не отключали. Конкретное успешное завершение очистки на скриншоте не подтверждено игровым запуском.

Проверка: просмотрены обе точки выбора места, сохранение задачи и возврат в Build, вызов скана, выбор одиночного детектора, владение приказами SCV. Проверены структура четырёх изменённых cpp и git diff --check. Сборка, компиляция и игровой запуск не выполнялись по указанию пользователя.
